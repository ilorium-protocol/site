# Security policy

Report vulnerabilities privately to **security@ilorium.com**. Please do not open a public issue.

- We acknowledge within 72 hours.
- We fix in coordination with you and credit you publicly if you wish.
- There are no bounties for now.

This repository is the static site for ilorium.com. It has no server, no accounts, no forms and no analytics.
The site loads nothing from third parties; see `README.md` for the Content Security Policy.
